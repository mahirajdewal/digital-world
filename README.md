# Digital World

This repository contains a minimal digital world built from first principles
to study intelligence, agency, and emergence.

The project is developed incrementally, with each version representing
a clear conceptual milestone.

---

## World v0 — Existence

World v0 establishes the foundational substrate:

- A grid-based environment
- A single embodied agent
- Deterministic world dynamics
- A stochastic (random) agent policy

### What this version does NOT include
- Learning
- Memory
- Rewards
- Planning
- Intelligence

This is intentional.

The goal of World v0 is to construct *existence before intelligence* —
a world where an agent can exist, act, and experience time.

All future behavior will be built on top of this substrate.
